# 憧れのハワイ航路

飛行機を操作してハワイを目指す、Python + pygame 製の横スクロールシューティングゲームです。
次々と現れる鳥人、トーテムポール、フライボードを撃ち落としながら進み、最後にボスを倒すとハワイに到着します。

## 必要環境

- Python 3（3.15 で動作確認済み）
- [pygame-ce](https://pyga.me/)（または pygame）

## セットアップ

```bash
python3 -m venv .venv
.venv/bin/pip install pygame-ce
```

> Python 3.15 向けには本家 `pygame` のビルド済みパッケージ（wheel）が配布されていないため、互換フォークの `pygame-ce` をおすすめします。コードは `import pygame` のままで動きます。

## 起動

```bash
.venv/bin/python main.py
```

## 操作方法

| キー | 動作 |
| --- | --- |
| Enter | ゲーム開始（タイトル画面）／リトライ（ゲームオーバー画面） |
| ↑ ↓ ← → | 飛行機の移動 |
| Space | ショット／エンドロールからタイトルへ戻る |
| Esc | ゲーム終了 |

### ゲームのルール

- ライフは 100 です。敵や敵の弾に当たると減り、0 になるとゲームオーバーです。
- ロコモコ丼を取るとライフが 20 回復します。
- 一定の距離を飛ぶとボスが登場します。ボスを倒せばクリアで、エンドロールでスコアと最大コンボ数が表示されます。

### デバッグ用の隠しコマンド

`stage_hawaii.py` の `DEBUG` を `True` にすると有効になります（初期値は `False`）。

| キー | 動作 |
| --- | --- |
| 1 | ライフを 1 にする |
| 2 | ハワイ（ボス）の直前までワープする |

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `main.py` | エントリーポイント |
| `application.py` | メインループとステージの切り替え（タイトル → ハワイ → エンドロール） |
| `renderer.py` | 画面（1280×720）の描画と、画像・フォントの管理 |
| `sound_mixer.py` | BGM・効果音の再生 |
| `collision.py` | 当たり判定 |
| `stage_*.py` | 各ステージ（タイトル、ゲーム本編、エンドロール） |
| `actor*.py` | 自機、敵、弾、アイテム、背景などのキャラクター |
| `layout_hawaii.txt` | 敵の出現パターン |
| `layout_debug.txt` | デバッグ用の出現パターン |
| `Asset/` | 画像・音声・フォント |

### 敵の出現パターン（`layout_*.txt`）

1 行に 1 体ずつ、以下の形式で書きます。`#` で始まる行と空行は読み飛ばされます。

```
# 出現フレーム, x座標, y座標, 種類, 行動タイプ
100, 1300, 100, 0, 0
```

- **種類**: `0` = 鳥人、`1` = トーテムポール、`2` = フライボード
- **行動タイプ**: 敵ごとの動きのパターン番号

デバッグ用のパターンを使うときは、`stage_hawaii.py` の `self.layout_filename` を `layout_debug.txt` に切り替えてください。

## 素材
